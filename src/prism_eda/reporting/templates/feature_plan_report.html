Feature cost and fallback rate

Cost is exclusive: work a feature shares with others is not charged to it, so the column sums to the whole rather than counting a shared subtree once per feature that reached it. A fallback is a computation that produced nothing usable, which is not the same as a value that happens to equal the default.

Measured is what this run cost on this machine. Estimated is derived from the operations in the plan and is what the cost alert above uses, because a finding built on the clock fires at random under load. The two disagree when a feature is cheap at this size and expensive at another — an opaque feature costs little over a hundred entities and dominates over a million.
